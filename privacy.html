このツールについて

「momoyuki-shorts」は、作者本人が制作した動画を、作者本人のYouTubeチャンネルへアップロードするためだけに使う個人用ツールです。一般の利用者向けには提供していません。

取得する情報と使い道

Googleアカウントでの許可を通じて、YouTubeへ動画をアップロードする権限（youtube.upload）のみを利用します。この権限は、作者自身のチャンネルに動画・タイトル・説明文をアップロードする目的にだけ使います。

他のユーザーの情報、視聴履歴、連絡先などの個人情報を取得・保存・第三者に提供することはありません。

YouTube API サービスの利用

本ツールは YouTube API サービスを使用しています。利用にあたっては YouTube 利用規約 および Google プライバシーポリシー が適用されます。

許可の取り消し

本ツールに与えた権限は、Googleアカウントのセキュリティ設定からいつでも取り消せます。

お問い合わせ

本ツールに関するお問い合わせは、YouTubeチャンネルの概要欄からご連絡ください。

Privacy Policy (English)

"momoyuki-shorts" is a personal tool used solely by its creator to upload the creator's own videos to the creator's own YouTube channel. It is not offered to the public.

It uses only the YouTube upload permission (youtube.upload), and only to upload videos, titles and descriptions to the creator's own channel. It does not collect, store or share any other personal data.

This tool uses YouTube API Services. By using it, you are agreeing to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google Account permissions.
